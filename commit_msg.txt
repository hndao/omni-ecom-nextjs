feat: Implement Account Settings and Address Book pages (#10, #11)

This commit implements GitHub issues #10 (Account Settings Page) and #11 (Address Book Page).

## Account Settings Page (#10)
- Created app/[locale]/account/settings/page.tsx (server component wrapper)
- Created app/[locale]/account/settings/SettingsClient.tsx with:
  * Profile settings form (first name, last name, email, phone)
  * Password change form with validation
  * Tab navigation between Profile and Password sections
  * Form validation and error handling
  * Loading and saving states
  * Success/error notifications

## Address Book Page (#11)
- Created app/[locale]/account/addresses/page.tsx (server component wrapper)
- Created app/[locale]/account/addresses/AddressesClient.tsx with:
  * List all saved addresses in responsive grid
  * Add new address modal form
  * Edit existing address functionality
  * Delete address with confirmation
  * Set default shipping/billing address
  * Address type badges (shipping/billing)
  * Default address indicator (star icon)
  * Empty state with call-to-action
  * Form validation using validateAddress()
  * Formatted address display

## Address Management Library
- Created lib/addresses.ts with:
  * getAddresses() - Fetch all customer addresses
  * getAddress(id) - Fetch specific address
  * createAddress(data) - Create new address
  * updateAddress(id, data) - Update existing address
  * deleteAddress(id) - Delete address
  * setDefaultAddress(id) - Set address as default
  * validateAddress(data) - Client-side validation
  * formatAddress(address) - Format address for display
  * getAddressTypeLabel(type) - Get localized type label

- Uses existing backend APIs:
  * PUT /api/auth/profile - Update customer profile
  * PUT /api/auth/change-password - Change password
  * GET /api/customer/addresses - List addresses
  * POST /api/customer/addresses - Create address
  * PUT /api/customer/addresses/{id} - Update address
  * DELETE /api/customer/addresses/{id} - Delete address
  * POST /api/customer/addresses/{id}/set-default - Set default
